# OneGuard LPG

Smart LPG cylinder level and leak monitoring system with Neo-Brutalist dashboard, 3D cylinder status visualizer, and alert management.

## Tech Stack
- TanStack Start & Router
- React 19
- Tailwind CSS
- Three.js & @react-three/fiber
- Lucide React & Framer Motion
- Vitest

## Getting Started

```sh
npm install
npm run dev
```

## Testing

```sh
npm run test
```
